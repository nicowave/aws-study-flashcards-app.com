🚀 QUICK START (5 STEPS)
══════════════════════════════════════════════════════════════════

Step 1: READ THE DOCUMENTATION
   └─ Open SETUP_INSTRUCTIONS.md and follow it carefully

Step 2: SETUP FIREBASE (15 minutes)
   ├─ Create Firebase project
   ├─ Enable Email/Password auth
   ├─ Enable Firestore
   └─ Copy your Firebase config

Step 3: COPY FILES TO YOUR PROJECTS
   ├─ Copy shared/* to each site's src/
   ├─ Update firebase.config.js with your credentials
   └─ Replace App.jsx for each site

Step 4: UPDATE DEPENDENCIES
   └─ Run: npm install (in each project)

Step 5: DEPLOY
   ├─ chmod +x deploy/universal-deploy.sh
   └─ Run deployment script for each site

📝 FILE COMPARISON WORKFLOW
══════════════════════════════════════════════════════════════════

For each site:

1. Backup your current files:
   cp src/App.jsx src/App.jsx.backup

2. Compare provided App.jsx with yours:
   - Keep your existing component imports
   - Merge the AuthProvider wrapper
   - Add UserBadge component

3. Copy shared files exactly as-is:
   - sharedAuth.js
   - AuthContext.jsx
   - AuthScreen.jsx
   - UserBadge.jsx
   - All CSS files

4. Update Firebase config with your credentials

5. Test locally before deploying:
   npm run dev
